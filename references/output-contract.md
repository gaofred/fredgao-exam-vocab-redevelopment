## 1. 文档顺序

按试卷原顺序。典型包：

```text
标题
材料来源
使用说明（含本卷范围与分层建议）

阅读A篇（★☆☆☆｜A2–B1）
I. 词汇变形与拓展
II. 短语积累与翻译
III. 句式分析与仿写

阅读B篇
...

阅读C篇
...
IV. 语法填空改编

阅读D篇
...
IV. 语篇逻辑排序

七选五
...
IV. 语篇逻辑排序

完形填空
...
IV. 叙事迁移

语法填空
I. 词汇变形与拓展
II. 短语积累与翻译
III. 长难句分析与翻译

应用文写作
...
IV. 句式与微写作迁移

读后续写
...
IV. 环境或动作微写作
```

不补不存在的板块。只要部分板块时，在 `使用说明` 写明范围。

板块标题必须与 `references/module-registry.json` 完全一致。C/D 篇的 IV 形态由体裁决定，上面只是示例，不是固定顺序。

## 2. 学生版与教师版边界

学生版可以有：

- 作答所需的源词、原句（含段落定位）；
- 空行、词库、中文提示、任务指令；
- 题目原文与续写所给首句；
- 难度星级。

学生版不得有：

- `参考答案`、`答案解析`、`正确顺序`、`参考范文`、已填好的空；
- `【答案与点拨】`、`【参考表达】` 字样；
- 红色系字体、隐藏文字、批注、页眉页脚中的答案；
- 教师推理过程与 QA 备注。

教师版保留学生版全部题干原文与编号，答案放在明确分隔的答案区。开放题标 `参考表达`。

## 3. 教师版答案呈现

- 答案区紧跟该板块题目之后；用户要求「学生版在前」时改放卷末附录。
- 词形题给完整词链与词义。
- 短语题给语境中文义。
- 句式题给结构指认 + 一条自然模型句。
- 改编语法填空给编号串 + 每空一行依据。
- 逻辑排序给顺序 + 逻辑链说明。
- 四项/三项要素见 `quality-rules.md` 第 8 节，缺项即不合格。

## 4. 排版硬规矩

黑白可打印，不靠样式、不靠颜色传递结构。

**禁项（脚本会查）**

- 禁用 Word 内置标题样式（Heading 1–9 / 标题 1–9 / Title / TOC Heading）；
- 禁用大纲级别；
- 禁用目录域（TOC）；
- 禁用自动编号（auto numbering）；
- 不用表格做作答横线。

理由：标题样式一改，全文层级和目录一起崩；学校模板套用时最容易出问题。

**层级只靠两件事：加粗 + 顶格。**

| 层级 | 字号 | 格式 |
|---|---|---|
| 文件首标题 | 16 pt | 加粗、居中 |
| 篇标题 | 15 pt | 加粗、顶格，后接（★★★☆｜B2） |
| 板块标题 | 13 pt | 加粗、顶格，后接（★★★☆） |
| 正文与题目 | 11.5 pt | 常规 |
| 答案行 | 11.5 pt | **不加粗**，紧接题目，不空行 |

**其他**

- 拉丁 Times New Roman；中文 宋体 / Songti SC / SimSun。
- 行距 1.5；段前段后 0；标题与题目不加首行缩进。
- 作答区：独立成行、顶格，整行下划线（连续下划线字符约 44–48 个，或段落下边框）。写作题给 6–8 行。
- 题目与其作答行尽量同页，不在短题与横线之间分页。
- 少用表格；必须用时防窄列与跨页断行。
- 需要署名时统一放页脚：`公众号：佛瑞德英语教学`，不得夹带答案信息。

## 5. 难度标注

- 篇标题：`阅读C篇（★★★☆｜B2）`
- 板块标题：`I. 词汇变形与拓展（★★★☆）`
- 学生版与教师版都标；学生版用于自主选题与分层。
- 星级口径见 `section-blueprints.md` 第 10 节，不用五星。

## 6. 文件命名

```text
{试卷名}_二次开发（学生版）.docx
{试卷名}_二次开发（教师版）.docx
{试卷名}_二次开发QA.json
```

需要 HTML 时追加 `_二次开发（学生版）.html`，命名与 docx 保持一致。文件名不得含答案提示。

## 7. 内容模型 schema

两版必须从同一个模型派生，模型字段固定如下。模型落成 `content.json`，与两版 docx 同目录，便于返工时只改这一份。

```json
{
  "title": "试卷名",
  "source": "来源与缺失说明",
  "usage": ["使用说明 1", "使用说明 2"],
  "sections": [
    {
      "label": "阅读C篇",
      "stars": "★★★☆",
      "cefr": "B2",
      "genre": "说明（现象解释）",
      "note": "教研说明，只进教师版",
      "blocks": [
        {
          "title": "IV. 语法填空改编",
          "stars": "★★★★",
          "mode": "closed",
          "note": "150 词，8 空（5 提示＋3 无提示）",
          "items": ["题干或语段，空处写 ____1____"],
          "answers": ["1. 答：caused　辨：…　错：…　换：…"]
        }
      ]
    }
  ]
}
```

字段约束：

| 字段 | 必填 | 约束 |
|---|---|---|
| `sections[].label` | 是 | 必须等于注册表 `sections[].label` |
| `blocks[].title` | 是 | 必须等于注册表 `modules[].title`；**不含星级**，星级只由 `stars` 字段渲染 |
| `blocks[].mode` | 是 | `closed` 用 `答/辨/错/换`，`open` 用 `参/忌/换`，与注册表 `answer_mode` 一致 |
| `blocks[].items` | 是 | 每项一行；题号从 1 连续；整行只有下划线表示作答横线 |
| `blocks[].answers` | 教师版 | 条数必须等于该板块题号数，编号一一对应 |
| `blocks[].lines` | 否 | `open` 类需要作答行数时给整数（写作类默认 6，微写作默认 3），由渲染层按数追加横线 |
| `sections[].note` / `blocks[].note` | 否 | 只进教师版，学生版出现即判泄漏 |
| `sections[].stars` / `blocks[].stars` | 是 | 四星为上限，口径见 `section-blueprints.md` 第 10 节 |

渲染约定，由 `scripts/render_packet.py` 执行（缺 `python-docx` 时照本节手工实现，不得省项；`render_packet.py` 已内置以下四条，改脚本时不要破坏）：

- **编号空 `____1____` 原样保留**，不参与下划线替换，否则空号会丢；
- 其余连续三个以上下划线替换为等宽空白（约 10 个字符的半角下划线）；
- 整行只有下划线的项，替换为段落下边框（占满整行，不随字体宽度变化）；
- `note` 只写教师版。

## 8. QA 报告

`schema_version` 为 2，字段：

- 源文件、检测到的板块、`detection_source`（显式标签 / 结构解析）、每篇体裁判定与 IV 形态及子形态（含覆盖默认值的理由）；
- 请求范围与实际生成范围、`omitted_sections`（省略的板块与原因）；
- 学生版/教师版板块对齐结果；
- 题号闭合结果：缺号、多号；
- 正文泄漏与深层泄漏（页眉页脚、批注、脚注、隐藏文字、彩色字体、高亮）；
- 排版检查（标题样式、目录域、自动编号、加粗答案行）；
- 难度星级分布；
- `ambiguities`：源文歧义或 OCR 修正记录，脚本只留空数组，由 agent 填写；
- `manual_segment`：是否有板块边界由人工切分（脚本默认 false）；
- DOCX 结构与渲染状态。

不展示内部推理链，只记结论与可执行的告警。

## 1. 取材三条铁律

违反任何一条，整套材料失去「二次开发」的资格，退化成一份新编练习。

- **原句必须回流。** III 层的原句一字不差引自本卷，句后标段落定位（`（C篇 第3段）`），学生拿着原卷能对上位置。改写过的句子不许叫原句。
- **仿写必须离场。** 仿写句必须换人、换事、换场景。只换主语的仿写等于抄写，不算产出。
- **改造不是新造。** IV 层复用原篇的事实链与逻辑顺序，只做考点化手术（设空、调序、抽框架）。不允许另写一篇冒充改编；也不允许把不相邻的句子拼成一段。

判断方法：把成品遮住标题，让同事只看 IV 层能否说出「这是哪一篇改的」。说不出就是新造。

## 2. 源文保真

- 候选词库从所给试卷建，包括语篇、题干、选项。
- 保持原文意义。OCR 明显损坏可保守修正，但必须记录改了什么。
- 不编造文章来源、官方答案或原文措辞。
- 无据可依的答案在工作笔记里标 `待核`，不得作为已确认的教师材料。

## 3. 词族完整性

接受：

- `emit → emission → emissions`
- `sustain → sustainable → sustainability`
- `analyze → analysis → analyses`
- `destroy → destruction`

拼写相似不等于派生。以下须拒收或改标为 `拓展`：

- `important → import`：课堂词族意义上无关。
- `precious → price`：历史同源但非透明能产派生，只能作词汇拓展，且要有用才收。
- `opportunity → occasion`：同义拓展，不是构词。
- `carbon → decarbonization`：真词基是 `decarbonize`，要讲前缀与后缀；无文本依据不得把 `carbon` 写成源动词。

每个目标词逐项核对拼写、可数性、单复数、词性、语域、语境义。优先收考试常见派生，不收罕见的词典可能性。

## 4. 短语选取

- 取完整可用的单位：`account for`、`be responsible for`、`make way for`、`rely on`、`have every intention of doing`。
- 保留必需的助词与补足成分。
- 给语境中文义，不给词典义清单。
- 拒收变形或不合习惯的语块。例：优先 `start one's day off well`，不要 `start one's day off good`，除非是引用并明确纠正原文错误。
- 少用专有名词与狭窄技术标签，除非不懂就读不下去。

## 5. 句式分析与仿写

- 叫出真实结构：动名词作主语、形式主语 `it`、分词作伴随、并列不定式、让步状语从句、同位语、定语从句，或其他精确特征。
- 先找主句，再找修饰成分。
- 仿写保留目标结构与时态逻辑。
- 用新语境与自然英语，不做逐字汉译。
- 教师答案给一条好模型；任务开放时标明这不是唯一可接受答案。

## 6. 改编语法填空

- 小语篇连贯，事实忠实。允许改写措辞，但事实链不得变形。
- 有提示的空，填入后词形必须明显变化；不许让学生原样照抄提示词。
- 无提示的空要有可辩护的唯一答案，或明确给出可接受集。
- 逐空校验：时态对时间标记、语态对语义角色、非谓语形式对句法位置。
- 不把个人文风偏好当语法规则考。
- 词数 120–170，8 空，5–6 提示 + 2–3 无提示，语法点不机械重复。

## 7. 写作支持

- 应用文的理由与表达必须挂到题干的具体读者、目的与场景上。
- 续写语言必须挂到实际人物、冲突、物件、动作与两个首句上。
- 用具体可复用语块，不用空泛形容词堆砌。
- 学生练习要留白：留出书写位置，提示不得把答案泄出来。

## 8. 教师版三件套

**只给答案的教师版不合格。** 每个板块的答案区按题性分两种版式，四项/三项缺一不可。

封闭题（`【答案与点拨】`）：

| 要素 | 要求 |
|---|---|
| `答：` | 答案本身，词形完整 |
| `辨：` | 为什么是这个，不是干扰项或近义形式 |
| `错：` | 典型错误形态：拼写、词性、时态、搭配 |
| `换：` | 换一个场景可复用的表达或完整例句 |

开放题（`【参考表达】`）：

| 要素 | 要求 |
|---|---|
| `参：` | 一条自然参考表达，不标唯一答案 |
| `忌：` | 学生最容易走偏的写法 |
| `换：` | 可迁移到的另一场景或可替换成分 |

排版：答案区紧跟该板块题目之后，答案行不加粗、不空行，编号与学生版逐条对应。

示例：

```text
【答案与点拨】
1. 答：destruction　辨：destroy 为及物动词，名词化取 -tion 而非 -ment　错：误作 destroyment / destory　换：The storm caused widespread destruction of crops.
2. 答：sustainable　辨：修饰 development 需形容词，sustain 不能直接作定语　错：误填 sustained（指「持续的」而非「可持续的」）　换：a sustainable farming model
```

## 9. 答案闭合

每个封闭题逐项核：

1. 空数与答案数一致；
2. 词性与屈折形合句；
3. 所列备选没有第二个也能自然成立；
4. 教师版编号与学生版编号逐条对应；
5. 解析指出具体依据：词形、句法、搭配或语篇关系。

开放仿写任务的教师答案标 `参考表达`，不标 `唯一答案`。

## 10. 难度标注

- 篇级星级按四维（词频层级、句法嵌套、抽象度、推理步数）定，格式 `★★★☆｜B2`。
- 板块星级默认随篇级，允许 ±1 星，但要能说出理由（例如词汇题只取了篇内高频词，可降一星）。
- 星级必须可辩护：被问到「为什么这篇是三星」时，要能指出具体词、具体句、具体推理步。
- 不用五星。五星意味着这篇不该进高三材料。

`python scripts/validate_packet.py` 会核对空数与编号，星级靠人工判断，不进脚本。

## 11. 成稿语言终检

全部生成英语逐项过：

- 冠词、主谓一致、时态、单复数、补足成分；
- 搭配与语域；
- 汉译英式的僵硬表达；
- 无意的 C1/C2 堆砌；
- 重复的通用语境（每篇都在讲「学生参加志愿活动」）；
- 事实性夸大；
- 从加粗、颜色、表格、批注、页眉页脚或文件名泄漏答案。

## 12. 内容自审四查（`scripts/audit_content.py`）

`validate_packet.py` 查形式，这一节查内容——形式检查看不出「这句原文里根本没有」和「这个构词说明写错了」。

```bash
python scripts/audit_content.py content.json --exam 原卷.docx --report audit.json
```

### 查一：原句回流

句式层的引句必须能在原文里逐字找到。比对前做归一化：去空白、去标点、全半角统一、去生词注释括号（原卷常在生词后加「（盖子）」这类中文，不去掉会误判）。

三种结果分开处理：

- **找不到** → error。引句被改写过、拼接了，或跨段拼起来的。
- **原文带空**（完形、语法填空）→ warning。这两类板块的原文本身有空格，引句必然要还原空位（如原文 `ways to ____21____ his neighbors`，引句写 `ways to support his neighbors`），机器无法判定还原词对不对，必须人工核对。
- **引句在原文中未断句** → error。长句截取须补省略号（`……`），否则读者会以为原文到此处结束。

### 查二：圈号完整

①②③ 必须每题从 ① 起、连续、各占一行。两处常见硬伤：一行挤进两个圈号（`② ③ 仿写：……`，等于 ② 的设问丢了）；跳号（只有 ①③）。

### 查三：构词自洽

「辨」里声称的变换必须与源词、答案词的实际词形相符。目前覆盖高置信规则：

| 声称 | 校验 |
|---|---|
| y 变 i | 源词须以 y 结尾 |
| 去（掉词尾）e | 源词须以 e 结尾 |
| e 结尾保留 | 源词与答案词都须以 e 结尾 |
| -able 变 -ability | 源词以 able 结尾，答案以 ability 结尾 |
| -ble 变 -bility | 源词以 ble 结尾，答案以 bility 结尾 |
| -ity 变 -ify | 源词以 ity 结尾，答案以 ify 结尾 |

只校验能机械判定的规则，其余（`-tion 名词化`、`-ment 名词化` 等）留给人看。宁可漏报，不报错。

### 查四：答案对齐

按题号比对，不按行数——开放题的答案常跨多行（一条答案里含 ① ② ③ 三小问）。缺号即 error。

### 处置

error 一律回内容模型改，重新生成两版；warning 逐条人工过。改完重跑两条命令，都 PASS 才交付。

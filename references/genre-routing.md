## 1. 为什么不能只按篇位分流

旧规则是「A/B 篇只做三模块、C/D 篇加语法填空改编」。这条规则把**篇位**当成了**体裁**的替身：默认 A 是应用文、B 是记叙文、C/D 是说明文或议论文。

这个等价关系近年已经不成立：

- C/D 篇出现过完整记叙（人物特写、成长故事），对它做语法填空改编会破坏时间线和人物动作，改出来的语篇读起来像案情摘要。
- A 篇出现过科普说明（新技术介绍、活动方案背后的原理），只做三层语块就浪费了它稳定的事实链。
- D 篇出现过带强论点的评述，把它当说明文做 IV-A，等于把论证结构压平成信息罗列。

所以判定顺序必须是：**先看这篇是什么体裁，再决定做哪种篇级改造**。篇位只决定模块数量与难度基线，不决定 IV 形态。

## 2. 四类体裁的识别清单

读完全文后按下列线索定类。线索是判据不是公式，冲突时以**语篇目的**为准：作者想让读者「知道发生了什么」是记叙，「弄懂一个机制」是说明，「接受一个判断」是议论，「照着做一件事」是应用。

| 体裁 | id | 主线索 | 反面线索（出现即警惕误判） |
|---|---|---|---|
| 记叙 | `narrative` | 过去时为主；第一人称或明确人物；时间状语成链（at first / then / years later）；有引语；动作—反应—结果 | 大量一般现在时、无人物、段落按主题而非时间推进 |
| 说明 | `expository` | 一般现在时；定义句（is / refers to / is known as）；被动语态；数据与百分比；机制、流程、分类 | 有明确对立观点与被反驳的一方；通篇人物行动 |
| 议论 | `argumentative` | 转折与因果标记密集（however / therefore / in fact）；情态动词；主张 + 证据；作者立场可摘出 | 通篇客观描述、无评价性形容词、无反驳对象 |
| 应用 | `practical` | 祈使句；联系方式、时间地点清单；短句多；for further information / please / if you | 长段落连贯叙述、学术术语集中 |

混合体裁（夹叙夹议、说明中带评价）按**承载主要考点的那一层**定类：题目集中在作者态度就按议论，集中在事实细节就按说明。

## 3. 体裁 → IV 形态对照表

| 体裁 | 首选 IV | 备选 | 选择理由 |
|---|---|---|---|
| 记叙 `narrative` | `IV-C` 叙事迁移 | `IV-E` 微写作迁移 | 动作链与情绪变化是它唯一不可替代的教学价值；改写会毁掉它 |
| 说明 `expository` | `IV-A` 语法填空改编 | `IV-B` 语篇逻辑排序 | 事实链稳定、术语可考、改写后不失真 |
| 议论 `argumentative` | `IV-B` 语篇逻辑排序（议论篇用句序排列） | `IV-D` 长难句拆解与翻译 | 论点—论据—让步的结构本身就是考点 |
| 应用 `practical` | `IV-E` 微写作迁移 | `IV-A`（仅当语言密度足够） | 场景真实，直接迁移到写作最划算 |

## 4. 决定优先级：题型硬约束 > 体裁 > 篇位

```
第一层  题型硬约束（不可被覆盖）
        语法填空板块 → 三层制，永不设 IV
        七选五       → 固定 IV-B（题型本质是语篇逻辑）
第二层  体裁（可覆盖题型的默认值，但必须记录）
        完形填空默认 IV-C；若原文为说明文，改 IV-E 并在 QA 记录
        阅读 A–D 全部按体裁查表
第三层  篇位（只影响数量与难度，不影响形态）
        A 篇偏短 → 减少语块与句式数量
        C/D 篇偏难 → 星级上调
```

字数门槛：`min_words` 触发时不做 IV，并写明原因。

| 板块 | 门槛 | 触发后处理 |
|---|---|---|
| 阅读A篇 | 原文 < 200 词 | 只做三层，QA 记「篇级改造收益低于时间成本」 |
| 阅读B篇 | 原文 < 220 词 | 同上 |
| 阅读C/D篇 | 无门槛 | 必须设 IV |

## 5. 两个容易判错的场景

**C 篇是人物特写。** 表面像说明（介绍一个人），实际是记叙骨架（时间 + 行动 + 转折）。判断方法：把段落首句连起来读，如果构成时间线就是记叙。处理：走 `IV-C`，并从「他做了什么—为什么—结果如何」抽句式，不要抽术语派生词。

**A 篇是科普短文。** 表面像应用（排版条目化），实际是说明（解释原理）。判断方法：看有没有「因为…所以…」式的机制解释。处理：走 `IV-A`，改编时保留机制链；若不足 200 词则不做 IV，只把术语词族与机制句做透。

## 6. 记录要求

`exam_sectionizer.py` 会给出 `genre.guess` 与 `confidence`，这是**表面线索的猜测**，不是结论。每个板块必须：

1. 读原文确认或改写 `genre.confirmed`；
2. 在 QA 中写明最终体裁、`iv_form`、以及是否覆盖了默认值；
3. 覆盖时写一句理由，例如「C 篇为人物成长叙事，改走 IV-C，避免语法填空改编破坏时间线」。

`confidence < 0.45` 时脚本会主动告警，这类板块必须人工复核后才能进入命题步骤。
